# P03｜Work Binding 与连续性实现说明

## 实现范围

P03 只实现正式 Work 的 Runtime 边界，不进入 Matt 自动识别、Context Routing 或 Reconcile。

已实现：

- `WorkBinding` Domain；
- worktree identity；
- `work_start_revision` 首次绑定冻结；
- worktree binding SQLite persistence；
- session binding；
- session suppression；
- 跨 Host / 新 Session resume；
- 同 Work 重复 bind 幂等；
- 不同 Work 隐式替换 fail-closed；
- 多 Active Change 归属 ambiguity fail-closed；
- `work bind / current / suppress-session` CLI；
- `status` 显示当前 worktree managed Work。

## 核心不变量

```text
Project Snapshot Baseline != Work Baseline
```

`work_start_revision` 在正式 Work 首次绑定时取当前 Git HEAD，之后 Resume / Rebind 不得移动。

```text
Worktree Binding = 跨 Agent 当前工作
Session Suppression = 当前 Session 临时退出
```

Session suppression 不删除 Worktree Binding。

## 存储边界

Work Binding、Session Binding、Suppression 均只写入：

```text
.continuum-local/runtime.db
```

不得写入 `.continuum/` Durable Project State。

## 1. MVP 要证明的完整闭环

```text
init
→ detect project
→ open / detect Change
→ register Spec / Ticket
→ bind Work
→ route minimal context
→ Agent implementation
→ lifecycle checkpoint
→ Work Reconcile
→ Change Reconcile
→ New Snapshot
→ another Agent resumes
→ Archive
```

---

## 2. 已冻结，不再在本 Spec 重复争论

- Project-scoped / Opt-in；
- Local-first + 模块化单体；
- `.continuum/` Durable、Git tracked；
- `.continuum-local/` Ephemeral、gitignored；
- Change：`active / closed / superseded`；
- Worktree 提供跨 Agent continuity；
- Session suppression 只影响当前 Session；
- Lifecycle = state-derived + event-assisted；
- Ticket Reconcile ephemeral；
- Change Reconcile durable；
- Project Baseline ≠ Work Baseline；
- Interaction：`STATUS / NOTICE / DECISION / BLOCK`；
- Matt = Observe + Register，不 fork；
- Codex 默认静默；
- OMP Managed Work 使用 Single Ambient Widget；
- Live Project Federated Authority，Archive 时 materialize。

---

## 3. 已冻结的实现级技术决策

1. **实现语言**：TypeScript + Node.js 24 LTS；
2. **Runtime SQLite 驱动**：`better-sqlite3`，隔离在 `RuntimeStorePort` 后；
3. **Archive Source**：默认包含 Final Source Snapshot；完整 Git History 通过 `--with-history` 可选生成 `git bundle`。

以上已定稿，不再作为 Ticket 阶段开放项。

## v1.0.6 架构修正

P08 真实 OMP TUI 验收补充冻结 BLOCK Recovery Contract：BLOCK 只阻止不安全的正式实现，不得锁死整个 Agent Session；Return To Design 释放 Work Binding 但保留 unresolved blocker；只有显式 Resolve Block 后才允许重新 bind。


## v1.0.6 Host 可靠性修正

- OMP lifecycle handler 内的人机 UI 等待统一设置 25 秒 fail-closed timeout；
- design-phase BLOCK 不再等待第二次 selector；
- `/continuum-resolve-block` 作为显式、无二次确认的 Host command；
- Host watchdog 不再影响 BLOCK Resolution correctness。


## v1.0.6 Archive 收口

P10 正式实现 Project Archive：完成态 Live Federated Project 物化为 self-contained Archive。默认包含 Final Snapshot 对应源码快照；ADR / CONTEXT / Spec / Ticket / Evidence 按 Final revision 物化；Archive 自带 manifest 与 SHA256 校验；`--with-history` 可选完整 Git bundle；缺失 Required Authority 默认 fail-closed，只有 `--allow-incomplete` 可显式保留 incomplete Archive。

## v1.1.0 Global Host Integration 架构修正

P11 修正 Host Integration Scope：Codex / OMP Adapter 默认从 repo-local 改为 user-level Global Bridge。项目是否受控仍由 `.continuum/project.yaml` 决定；Global Bridge 在非 Continuum 项目必须 silent NOOP。

冻结：

```text
Machine Scope
├─ Continuum CLI
├─ Codex Global Bridge
└─ OMP Global Bridge

Project Scope
├─ .continuum/
└─ .continuum-local/
```

Agent 可通过 `continuum_init / continuum_status / continuum_doctor` 提供自然语言便利操作，但关键生命周期正确性继续由 Global Hook / Extension 确定性兜底。

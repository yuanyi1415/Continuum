# 14｜定稿技术决策

MVP 技术规格 v1.0.0 已无阻塞性开放技术选择。

## 1. 实现语言

冻结：

```text
TypeScript + Node.js 24 LTS
```

Core、CLI、MCP 与 Host Adapter 统一 TypeScript。

---

## 2. Runtime SQLite

冻结：

```text
SQLite + better-sqlite3
```

具体驱动必须隔离在：

```text
RuntimeStorePort
```

未来如切换 Node 内置 SQLite，不影响 Domain / Application。

---

## 3. Archive Source

冻结：

```text
默认：
Final Source Snapshot

可选：
--with-history → git bundle
```

Archive 的 self-contained 最低要求包含最终源码快照。

---

## 4. Ticket 阶段不得重新打开

- Local-first + 模块化单体；
- TypeScript + Node.js 24 LTS；
- Durable YAML / Runtime SQLite；
- better-sqlite3；
- Change 三状态；
- Worktree Continuity；
- Ticket ephemeral reconcile；
- Change durable reconcile；
- state-derived lifecycle；
- Codex / OMP UX 基线；
- Matt black-box；
- Federated Authority；
- Archive 默认包含 Final Source Snapshot。

## 5. Global Host Integration（v1.1.0）

冻结：

```text
Host Integration = User / Machine Scope
Project Activation = Project Scope
```

默认安装：

```bash
continuum setup
```

Global Bridge 使用 cwd 自动发现 `.continuum/project.yaml`；不存在时 silent NOOP。

新项目不得要求重复 `host install`。repo-local Codex / OMP Adapter 仅保留兼容 / 调试模式。

Agent-driven project tools 是 UX 便利层，不能替代 deterministic lifecycle interception。

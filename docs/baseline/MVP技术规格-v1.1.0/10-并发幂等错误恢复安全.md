# 10｜并发、幂等、错误、恢复与安全

## 1. 并发模型

MVP 支持：

- 多 Agent；
- 多 Session；
- 多 Git worktree。

### Work 级

Runtime State worktree-local。

### Project 级

Change Reconcile / Current advancement 使用 optimistic concurrency。

## 2. Durable Write Lock

同一 worktree / repo 内 Durable Mutation 使用 local advisory lock。

Lock 文件放：

```text
.continuum-local/locks/
```

不得提交 Git。

### Lifecycle Event



## 6. Fail-safe 原则

### 可以降级继续

- STATUS 渲染失败；
- NOTICE 渲染失败；
- Runtime diagnostic event 丢失。

### 必须停止

- DECISION 无法呈现且 blocking；
- Schema 版本过新；
- Snapshot CAS 冲突；
- N4；
- Authority 冲突；
- 关键 Evidence UNKNOWN 且完成条件要求 PASS。

---

## 7. Recovery

### Hook 丢失

下次：

```text
status / reconcile / stable checkpoint
```

重新派生。

### Runtime DB 损坏

```text
rename corrupt db
create new runtime db
recover from durable + Git
```

不得自动删除损坏文件。

### Durable YAML 损坏

fail closed。

给出：

```text
file
schema error
last known snapshot
recovery suggestion
```

---

## 8. Trust / Security

User-level Codex Hook / OMP Extension 属于可执行代码；legacy repo-local Adapter 同样属于可执行代码。

安装必须：

- 明确展示；
- 尊重 Host Trust UX；
- 不绕过 Host Trust；
- 不读取无关用户秘密；
- 不上传 Project 内容。

### Command Execution

Core 不直接执行任意 LLM 提供的 shell。

外部 command 通过明确 Port / configured command allowlist。

---

## 9. Path Safety

Archive / materialize：

- 防 `../` traversal；
- 不跟随越界 symlink；
- manifest 保存真实 source locator；
- copy 前后 hash。

## 10. BLOCK 不可绕过但必须可恢复

Fail-safe 不等于 Session deadlock。

- unresolved BLOCK 必须阻止 formal rebind；
- `continuum-off` 不得绕过 managed BLOCK；
- Host exit/help/status 必须始终可用；
- Return To Design 是安全降级路径，不等于 Resolve；
- Resolve Block 是显式用户确认动作。


## 11. P09 Recovery Safety（v1.0.5）

`doctor --recover` 可以自动执行：

- missing runtime DB rebuild；
- corrupt runtime DB quarantine + rebuild；
- Runtime schema forward migration；
- stale Runtime Work Binding cleanup（仅当其指向不存在的 Durable 节点）；
- Work Binding 仍存在时，从 Git State 补建丢 Hook 的 pending Work Reconcile。

不得自动执行：

- 猜测新的 Current Snapshot；
- 修改 invalid Durable YAML；
- 覆盖 newer Durable / Runtime schema；
- runtime 丢失后猜测原 Work owner；
- 伪造不存在的 Artifact Authority。

如果 Runtime 已丢失但 Current Snapshot 与 Git HEAD 有业务差异，只报告 unreconciled Git delta，并保留事实。

## 12. P11 Global Bridge Safety

Global Integration 必须满足：

- 非 Continuum Project silent NOOP；
- Global setup 不自动 init Repository；
- Legacy local Adapter 存在时 Global Bridge defer；
- 同一 Host Hook / Extension 重复 setup 幂等；
- Codex Hook merge 不删除用户其它 Hook；
- OMP Global Extension 仅覆盖 Continuum 自己的目标文件；
- Agent-facing `continuum_init` 只能在用户明确要求启用项目时使用；
- Global Bridge 不上传项目内容。

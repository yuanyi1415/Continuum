# 12｜测试策略与验收标准

## 1. 测试层级

```text
Unit
Contract
Integration
Host E2E
Scenario / Regression
```

---

## 2. Unit

覆盖：

- Change transition；
- Work baseline invariant；
- relation routing；
- interaction fallback；
- Knowledge Impact action mapping；
- snapshot construction；
- error mapping。

---

## 3. Contract Tests

每个 Port 必须有共享 Contract Test：

- ProjectStore；
- RuntimeStore；
- GitPort；
- ArtifactAuthorityPort；
- InteractionRenderer。

新增 Adapter 必须通过同一 Contract Suite。

## 4. Storage Integration

### YAML

### SQLite

- WAL；
- concurrent reads/writes；

---

## 5. Lifecycle Regression

必须永久保留前期 Spike 得到的回归场景：

1. Ad-hoc 不绑定；
2. Codex explicit intent bind；
3. freeze work baseline；
4. Codex → OMP resume；
5. business commit → one pending candidate；
6. new Codex session resume；
7. duplicate checkpoint dedupe；
8. lost hook recovery；
9. session suppression 不删除 worktree binding；
10. binding 前改动不进入 Work Reconcile。

---

## 6. Parallel Worktree

至少：

```text
Agent A / worktree A → P03
Agent B / worktree B → P04
```

要求：

- Ticket reconcile 不冲突；
- 合并实现后 Change Reconcile 正常；
- Current Snapshot 只在 integration boundary 推进。

---

## 7. Interaction E2E

### Codex

- normal silent；
- DECISION structured interaction；
- MCP unavailable → Hook Gate；
- BLOCK cannot continue silently。

### OMP

- aware silent；
- managed single widget；
- simple decision select；
- heavy decision overlay；
- block；
- suppression widget disappears。

## 8. Context Routing

构造：

- required；
- optional；
- historical；
- superseded。

断言：

- required loaded；
- optional 按需；
- historical 默认排除；
- no unrelated doc scan。

---

## 9. Archive

验证：

- manifest；
- artifact hash；
- missing report；
- offline readability；
- optional source bundle restore。

---

## 10. MVP 最终验收 Journey

```text
new repo
→ continuum init
→ open Change
→ register Spec / Tickets
→ Codex implement P03
→ OMP resume P03
→ reconcile work
→ finish remaining work
→ Change Reconcile
→ Snapshot advances
→ fresh Agent reads status/context
→ archive
```

必须在真实 Repo 跑通，不允许只用 mock。

## 11. BLOCK Recovery 回归（v1.0.1）

1. N4 BLOCK 阻止 managed implementation；
2. Return To Design 后 Work Binding 清除；
3. BLOCK 仍 pending；
4. 普通设计 prompt 可以继续；
5. rebind 同一受影响 Ticket 再次被 BLOCK；
6. Session Suppression 不能绕过；
7. explicit Resolve Block 后 formal rebind 成功；
8. OMP `/quit / help / continuum-status` 在 BLOCK 后仍可用。


## 12. P09 Doctor / Migration / Recovery 回归（v1.0.5）

永久加入：

1. Durable v0 → v1 migration + backup + idempotency；
2. Durable newer schema fail closed；
3. Runtime v1 → v2 transactional migration；
4. Runtime newer schema 不恢复、不覆盖；
5. runtime.db missing → rebuild；
6. runtime.db corruption → quarantine + rebuild；
7. lost Hook → Work Binding + Git state 补建 pending reconcile；
8. broken Current pointer → 明确失败且不得猜 Snapshot；
9. missing Artifact Authority / orphan Relation → authority failure；
10. Host Adapter missing / drift → diagnostic；
11. P01～P09 全量 regression。


## 12. P10 Archive 回归（v1.0.6）

永久加入：

1. Final Snapshot / Durable state / required artifacts / source snapshot 物化；
2. HEAD 晚于 Final Snapshot 时仍使用 Final revision；
3. 原 Repo 删除后 Archive 可独立读取与 verify；
4. Required Artifact 缺失默认 fail-closed；
5. `--allow-incomplete` 生成 incomplete Archive；
6. `--with-history` bundle 可 clone 并恢复 final revision；
7. checksum 可检测篡改；
8. active Change 项目禁止 Archive；
9. CLI JSON 创建/校验契约。

## 13. P11 Global Host Integration 回归（v1.1.0）

永久加入：

1. `continuum setup` 可在非 Git 目录执行；
2. Codex user Hook + MCP 安装幂等；
3. OMP user Extension 安装幂等；
4. 非 Continuum 项目 Codex / OMP Global Bridge silent NOOP；
5. 新项目 `continuum init` 不生成 `.codex/.omp`；
6. Codex Global Hook 可根据 explicit implement intent 建立 Work Binding；
7. OMP Global Extension 可跨 Host 恢复同 worktree Work；
8. Global Bridge 提供 `continuum_init / status / doctor`；
9. legacy repo-local Adapter 存在时 global defer；
10. P01～P11 全量 regression。

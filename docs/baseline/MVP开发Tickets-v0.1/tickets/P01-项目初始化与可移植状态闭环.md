# P01｜项目初始化与可移植状态闭环

## 目标

完成第一条真实纵向链路：

```text
Git Repo
→ continuum init
→ Durable + Runtime initialized
→ continuum status
→ clone repo
→ continuum status
```

## 范围

实现：

- TypeScript / Node 24 工程骨架；
- Domain / Application / Ports / Adapters 依赖约束；
- `ProjectStorePort` YAML 初版；
- `RuntimeStorePort` SQLite 初版；
- `GitPort` 最小实现；
- Project / initial Snapshot；
- `current.yaml`；
- Runtime migrations；
- `.continuum-local/` gitignore；
- `continuum init`；
- `continuum status [--json]`；
- 最小 `doctor`：schema/Git/runtime connectivity。

## 验收

1. 在新 Git Repo 执行 `continuum init`；
2. 生成合法 `.continuum/`；
3. 生成 `.continuum-local/runtime.db`；
4. Git tracked 只包含 Durable State；
5. `status --json` 可读取当前 Snapshot；
6. commit 后 clone 到新目录；
7. 新目录安装 CLI 后无需旧 Runtime DB 即可读取项目状态。

## 不做

- Change；
- Ticket；
- Host Adapter；
- Reconcile；
- Archive。

## 依赖

无。

## 核心测试

- JSON Schema validation；
- atomic YAML write；
- SQLite migration；
- malformed project state fail-closed；
- repo identity 不随 clone path 漂移。

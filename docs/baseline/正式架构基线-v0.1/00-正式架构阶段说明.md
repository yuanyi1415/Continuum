# Continuum｜正式架构阶段说明 v0.1

**上游基准**：`Continuum-前期冻结基准-v1.0.0`  
**当前阶段**：Formal Architecture Gate  
**目标**：把已经验证过的产品事实，转换成可实现、可约束、可评审的正式系统架构。

---

## 1. 本阶段解决什么

本阶段只回答：

1. Continuum 的核心模块如何拆分；
2. 模块之间允许怎样依赖；
3. Durable Project State 与 Ephemeral Runtime State 如何分离；
4. Host Adapter、Lifecycle、Reconcile、Interaction 如何协作；
5. 哪些决策必须进入 ADR；
6. 什么条件满足后才能进入 Spec / Ticket。

---

## 2. 本阶段不做什么

暂不进入：

- 完整产品 Spec；
- CLI 命令全集；
- UI 视觉设计；
- Web Dashboard；
- Personal Knowledge Extraction；
- 复杂权限模型；
- 云端服务；
- 多 Agent Scheduler；
- 全量 Agent 生态适配；
- 正式代码实现。

---

## 3. 架构阶段工作顺序

```text
前期冻结基准 v1.0.0
        ↓
正式架构基线 v0.1
        ↓
ADR 逐项评审 / 冻结
        ↓
Architecture Gate
        ↓
MVP Spec
        ↓
Tickets
        ↓
Build
```

---

## 4. 本包状态说明

本包中的：

- **架构边界**：当前候选基线；
- **ADR**：均为 `Proposed`，尚未视为最终 Accepted；
- **具体文件格式 / Schema 字段**：只定义方向，不在本轮过度冻结。

后续 ADR 如被接受，则同步提升架构基线版本。

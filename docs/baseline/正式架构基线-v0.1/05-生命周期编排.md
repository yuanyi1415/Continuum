# 05｜生命周期编排

## 1. Activation Gate

所有 Host Event 先经过：

```text
Is Continuum Project?
        │
        ├─ No → NOOP
        │
        ▼
Is Session Suppressed?
        │
        ├─ Yes → NOOP
        │
        ▼
Is Managed Work bound?
        │
        ├─ No → Project-aware / mostly silent
        │
        ▼
Lifecycle Check
```

---

## 2. Work Intent

只有明确工作意图才能建立正式 Work Binding。

典型：

```text
/implement P03
```

或宿主 / Matt 等价的正式 Work 动作。

### 唯一归属

自动绑定。

### 多个可能归属

产生：

```text
DECISION
```

不得让 LLM 猜。

---

## 3. Binding

首次正式绑定：

```text
target = P03
worktree = current worktree
work_start_revision = Git HEAD at binding time
```

之后：

```text
Codex → OMP → Codex
```

共享同一个 Worktree Binding。

---

## 4. Stable Checkpoint

候选稳定边界：

### Codex

```text
Stop
SessionEnd
```

### OMP

```text
session_stop
session_shutdown
```

### Generic

```text
post-commit
explicit CLI check
```

Stable Checkpoint 只触发：

```text
CHECK
```

不是直接写 Project State。

---

## 5. Work Reconcile

判断：

```text
work_start_revision
vs
current_revision
```

若无真实变化：

```text
NOOP
```

若有：

```text
collect changed files
collect tests
collect review
classify knowledge impact
save/update pending reconcile
```

同一 Ticket 多 Commit：

> 更新同一个 Pending Candidate。

---

## 6. Knowledge Impact

```text
N0
Implementation only
→ silent

N1
Mechanical project state
→ auto

N2
Domain change
→ PROPOSE CONTEXT

N3
Architecture decision
→ DECISION / ADR

N4
Design or scope gap
→ BLOCK
```

正式实现可以不用暴露 N0-N4 给用户，它是内部分类。

---

## 7. Change Reconcile

触发条件候选：

- Change tickets 满足完成条件；
- 用户显式收口；
- Matt / Tracker 显示 Change implementation complete。

流程：

```text
load Change
load Spec
collect Ticket reconcile candidates
read relevant Authority
compare implementation vs intended state
produce Change Reconcile
```

结果：

```text
AUTO updates
PROPOSE knowledge changes
BLOCK unresolved conflict
```

只有满足 Gate：

```text
New Snapshot
→ Current advance
```

---

## 8. Failure Recovery

若 Hook 丢失：

```text
status / checkpoint
→ compare Snapshot / Work baseline / Git current
→ rediscover unreconciled changes
```

若 `.continuum-local` 丢失：

```text
reconstruct from durable state + Git + Tracker
```

因此：

> Native lifecycle improves responsiveness, not correctness.

# 10｜并发、幂等、错误、恢复与安全

## 1. 并发模型

MVP 支持：

- 多 Agent；
- 多 Session；
- 多 Git worktree。

### Work 级

Runtime State worktree-local。

### Project 级

Change Reconcile / Current advancement 使用 optimistic concurrency。

---

## 2. Durable Write Lock

同一 worktree / repo 内 Durable Mutation 使用 local advisory lock。

Lock 文件放：

```text
.continuum-local/locks/
```

不得提交 Git。

---

## 3. SQLite

## 4. 幂等

至少：

### Lifecycle Event

```text
host + session + event-id
```

或 cursor 去重。

### Work Reconcile

```text
worktree + work + current_revision
```

### Change Reconcile

```text
change + input_snapshot + implementation_revision_set
```

## 6. Fail-safe 原则

### 可以降级继续

- STATUS 渲染失败；
- NOTICE 渲染失败；
- Runtime diagnostic event 丢失。

### 必须停止

- DECISION 无法呈现且 blocking；
- Schema 版本过新；
- Snapshot CAS 冲突；
- N4；
- Authority 冲突；
- 关键 Evidence UNKNOWN 且完成条件要求 PASS。

---

## 7. Recovery

### Hook 丢失

下次：

```text
status / reconcile / stable checkpoint
```

重新派生。

### Runtime DB 损坏

```text
rename corrupt db
create new runtime db
recover from durable + Git
```

不得自动删除损坏文件。

### Durable YAML 损坏

fail closed。

给出：

```text
file
schema error
last known snapshot
recovery suggestion
```

---

## 8. Trust / Security

Repo-local Hook / OMP Extension 属于可执行代码。

安装必须：

- 明确展示；
- 尊重 Host Trust UX；
- 不绕过 Host Trust；
- 不读取无关用户秘密；
- 不上传 Project 内容。

### Command Execution

Core 不直接执行任意 LLM 提供的 shell。

外部 command 通过明确 Port / configured command allowlist。

---

## 9. Path Safety

Archive / materialize：

- 防 `../` traversal；
- 不跟随越界 symlink；
- manifest 保存真实 source locator；
- copy 前后 hash。

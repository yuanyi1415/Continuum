# 13｜非功能要求

## 1. 安装

MVP：

- 无 daemon；
- 无 Docker；
- 无外部 DB；
- install once；
- repo `init` ≤ 1 个主要动作。

---

## 2. 启动性能

目标：

```text
continuum status
P95 < 300ms
```

小中型 Repo 本地环境。

不把大型 Git diff 读取放在每次 status 必经路径。

---

## 3. Lifecycle Checkpoint

无代码变化：

```text
P95 < 500ms
```

有变化且不调用 LLM 语义分析：

```text
P95 < 1s + Git diff cost
```

LLM semantic reconcile 单独计时。

---

## 4. 可移植性

```text
git clone
→ continuum status
```

在安装 CLI 后应恢复 Durable Project State。

不能依赖旧机器 Session DB 才理解项目。

---

## 5. 可审计

Durable 项目事实必须：

- human-readable；
- Git diff 可见；
- source locator 可追踪；
- Change Reconcile 可解释 Snapshot 为什么变化。

---

## 6. 可诊断

```text
continuum doctor
```

至少检查：

- schema；
- Git；
- runtime DB；
- current pointer；
- orphan refs；
- missing artifact；
- Host Adapter 安装；
- Host capability。

---

## 7. Log

默认不刷屏。

本地结构化日志：

- error；
- lifecycle debug；
- host adapter diagnostics。

不得默认记录 Artifact 正文或用户 Prompt 全文。

---

## 8. 向后兼容

Durable Schema：

- 至少支持当前版本和上一个版本迁移；
- 不支持更高版本时 fail closed。

Host API 变化：

- capability detection；
- Adapter isolated；
- 不影响 Domain Schema。

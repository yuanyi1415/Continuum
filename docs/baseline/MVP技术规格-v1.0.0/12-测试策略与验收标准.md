# 12｜测试策略与验收标准

## 1. 测试层级

```text
Unit
Contract
Integration
Host E2E
Scenario / Regression
```

---

## 2. Unit

覆盖：

- Change transition；
- Work baseline invariant；
- relation routing；
- interaction fallback；
- Knowledge Impact action mapping；
- snapshot construction；
- error mapping。

---

## 3. Contract Tests

每个 Port 必须有共享 Contract Test：

- ProjectStore；
- RuntimeStore；
- GitPort；
- ArtifactAuthorityPort；
- InteractionRenderer。

新增 Adapter 必须通过同一 Contract Suite。

---

## 4. Storage Integration

### YAML

- atomic write；
- schema validation；
- conflict；
- malformed file；
- migration。

### SQLite

- WAL；
- concurrent reads/writes；
- busy timeout；
- migration；
- corruption handling。

---

## 5. Lifecycle Regression

必须永久保留前期 Spike 得到的回归场景：

1. Ad-hoc 不绑定；
2. Codex explicit intent bind；
3. freeze work baseline；
4. Codex → OMP resume；
5. business commit → one pending candidate；
6. new Codex session resume；
7. duplicate checkpoint dedupe；
8. lost hook recovery；
9. session suppression 不删除 worktree binding；
10. binding 前改动不进入 Work Reconcile。

---

## 6. Parallel Worktree

至少：

```text
Agent A / worktree A → P03
Agent B / worktree B → P04
```

要求：

- Ticket reconcile 不冲突；
- 合并实现后 Change Reconcile 正常；
- Current Snapshot 只在 integration boundary 推进。

---

## 7. Interaction E2E

### Codex

- normal silent；
- DECISION structured interaction；
- MCP unavailable → Hook Gate；
- BLOCK cannot continue silently。

### OMP

- aware silent；
- managed single widget；
- simple decision select；
- heavy decision overlay；
- block；
- suppression widget disappears。

---

## 8. Context Routing

构造：

- required；
- optional；
- historical；
- superseded。

断言：

- required loaded；
- optional 按需；
- historical 默认排除；
- no unrelated doc scan。

---

## 9. Archive

验证：

- manifest；
- artifact hash；
- missing report；
- offline readability；
- optional source bundle restore。

---

## 10. MVP 最终验收 Journey

```text
new repo
→ continuum init
→ open Change
→ register Spec / Tickets
→ Codex implement P03
→ OMP resume P03
→ reconcile work
→ finish remaining work
→ Change Reconcile
→ Snapshot advances
→ fresh Agent reads status/context
→ archive
```

必须在真实 Repo 跑通，不允许只用 mock。

# 03｜领域模型与不变量

## 1. Project

```yaml
project_id: prj_xxx
name: Work Agent
schema_version: 1
created_at: 2026-09-17T00:00:00Z
repository:
  identity: https://github.com/org/repo.git
```

### 不变量

- `project_id` 初始化后不可修改；
- Repository Identity 是 canonical identity，不随 clone path 漂移；
- 一个 Git worktree 只能属于一个 Continuum Project。

---

## 2. Snapshot

```yaml
snapshot_id: snap_xxx
project_id: prj_xxx
created_at:
baselines:
  - repository_identity:
    revision:
stage:
active_changes: []
blockers: []
next_gate:
last_reconcile:
```

### 不变量

- Snapshot immutable；
- Current Pointer 必须引用存在的 Snapshot；
- Snapshot 不复制 Spec / Ticket / ADR 正文；
- 只有 Change Reconcile 成功后允许创建新 Snapshot。

---

## 3. Change

状态：

```text
active
closed
superseded
```

### 允许迁移

```text
active → closed
active → superseded
```

禁止：

```text
closed → active
superseded → active
```

重新开启需求必须创建新 Change。

### 关键字段

```yaml
change_id:
title:
intent:
status:
created_at:
closed_at:
superseded_by:
spec_refs: []
ticket_refs: []
```

---

## 4. ArtifactRef

```yaml
artifact_id:
type:
authority:
locator:
version:
title:
metadata:
```

建议 `type`：

```text
context
adr
spec
ticket
review
evidence
document
other
```

### 不变量

ArtifactRef 不成为 Artifact 正文 Authority。

---

## 5. Relation

```yaml
relation_id:
from:
to:
type:
routing:
created_at:
```

`type`：

```text
belongs_to
blocked_by
governed_by
domain_context
evidence
supersedes
```

`routing`：

```text
required
optional
historical
```

### 不变量

- endpoints 必须可解析；
- `historical` 默认不进入 Context；
- Relation 是 Continuum 自己的 Authority。

---

## 6. Work Binding

Runtime entity：

```yaml
work_id:
worktree_id:
target_artifact_id:
change_id:
work_start_revision:
bound_at:
binding_source:
```

### 不变量

- 一个 worktree 同时最多一个 active formal Work；
- `work_start_revision` 首次绑定后 immutable；
- Resume 不改变 Work Baseline；
- 切 Host 不改变 Work Binding。

---

## 7. Session Suppression

```yaml
session_id:
host:
suppressed_at:
reason:
```

不变量：

> Session Suppression 不能删除 Worktree Binding。

---

## 8. Pending Work Reconcile

```yaml
work_id:
base_revision:
current_revision:
changed_files:
evidence:
knowledge_impact:
actions:
updated_at:
```

同一 Work 只有一个 Pending Candidate。

---

## 9. InteractionRequest

```yaml
id:
type: STATUS|NOTICE|DECISION|BLOCK
title:
message:
reason:
options: []
blocking:
created_at:
```

### 不变量

- `DECISION` 必须提供 options 或明确 free-form contract；
- `BLOCK.blocking = true`；
- Headless 环境不得自动选择 DECISION。

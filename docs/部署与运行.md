# Continuum 部署与运行方式

## 1. 不需要服务端部署

Continuum v1.1 仍然是 local-first CLI + Host Bridge：

```text
Developer Machine
├─ Git
├─ Node.js 24 LTS
├─ Continuum CLI
├─ Codex Global Bridge
├─ OMP Global Bridge
└─ Git Projects
   ├─ .continuum/
   └─ .continuum-local/
```

不需要 Docker、Daemon、MySQL、Redis 或单独服务器。

## 2. 每台机器安装一次

```bash
npm install -g "github:yuanyi1415/Continuum"
continuum setup
continuum doctor --global
```

## 3. 每个项目

不再安装 Host Adapter。

项目只需要显式 opt-in：

```bash
continuum init --name "Project Name"
```

也可以让 Codex / OMP 调用 `continuum_init`。

## 4. 正常启动

```bash
cd project
codex
```

或：

```bash
cd project
omp
```

Global Bridge 自动根据 cwd 判断是否是 Continuum Project。

## 5. 团队使用

`.continuum/` 进入 Git。

`.continuum-local/` 不进入 Git。

每名开发者只需在自己的机器上执行一次：

```bash
continuum setup
```

clone 一个已有 Continuum Project 后无需再次给该项目安装 Codex / OMP Adapter。

## 6. OMP Profiles

默认安装：

```text
~/.omp/agent/extensions/continuum.ts
```

若独立 Profile 使用其它 Agent Directory，通过：

```bash
PI_CODING_AGENT_DIR=<agent-dir> continuum setup --skip-codex
```

进行该 Profile 的 user-level setup。

## 7. 旧项目

旧项目级 `.codex/.omp` Adapter 继续兼容；Global Bridge 会 defer，避免重复事件。

新项目不再使用 repo-local Adapter。

该问题被判定为 Architecture Gap，而非单纯 UI bug。已新增 ADR-009 并修改 Core Contract。修正版生产验收必须额外验证：

1. BLOCK 阻止当前实现 Turn；
2. “返回设计 / Spec”释放 Work Binding但不解决 BLOCK；
3. Session 仍可执行 status / quit 并继续设计讨论；
4. unresolved BLOCK 阻止 P03 重新 bind；
5. `/continuum-resolve-block` 需要显式用户确认；
6. resolve 后 P03 才能重新 bind。

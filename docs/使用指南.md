# Continuum 使用指南

## 1. 第一次

机器上只做一次：

```bash
continuum setup
continuum doctor --global
```

## 2. 新项目

进入项目后直接打开 Codex / OMP：

```bash
codex
# 或
omp
```

告诉 Agent：

```text
给这个项目启用 Continuum。
```

Agent 调用 `continuum_init`。

CLI fallback：

```bash
continuum init --name "Project Name"
```

## 3. 未启用项目

如果没有 `.continuum/project.yaml`：

```text
Global Bridge silent NOOP
```

Continuum 不会自动接管。

## 4. 正式开发

普通问题：

```text
解释这个模块
```

保持 unmanaged。

明确实现：

```text
implement P03
```

进入 Managed Work。

## 5. 跨 Host

同一个 worktree：

```text
Codex 中开始 P03
→ 退出 Codex
→ 打开 OMP
→ OMP 从 Runtime State 恢复 P03
```

Host 不拥有 Work Continuity；worktree Runtime State 才拥有。

## 6. 状态

可以直接问 Agent：

```text
当前 Continuum 状态怎么样？
```

或：

```bash
continuum status
```

## 7. 诊断

机器：

```bash
continuum doctor --global
```

项目：

```bash
continuum doctor
continuum doctor --recover
```

## 8. 设计冲突

```text
发现设计冲突
→ 回到设计
→ 修改 Spec / ADR
→ 再次 implement
→ 确认重新开始
```

## 9. 收口与归档

```bash
continuum reconcile
continuum archive
```

需要 Git History：

```bash
continuum archive --with-history
```

# P11｜Global Host Integration & Zero-Ceremony Onboarding｜实现说明

## 1. 目标

把 P07 / P08 的默认 repo-local Host Adapter 改为 user-level Global Bridge：

```text
一次全局接入
→ 多项目自动发现
→ 项目是否启用仍由 .continuum/ 决定
```

## 2. 已实现

### Global Setup

```bash
continuum setup
continuum doctor --global
```

`setup`：

- 可在非 Git 目录执行；
- 自动检测 Codex / OMP；
- Codex 安装用户级 Hook + MCP；
- OMP 安装用户级 Extension；
- Host 不存在时跳过并给出 warning；
- 可通过 `--skip-codex / --skip-omp` 控制。

### Codex Global Bridge

默认路径：

```text
$CODEX_HOME/hooks.json
$CODEX_HOME/config.toml
```

若未设置 `CODEX_HOME`，使用：

```text
~/.codex/
```

生命周期入口：

```text
SessionStart
UserPromptSubmit
Stop
SessionEnd
```

Global Hook 调用：

```text
continuum host codex hook --global
```

并注册全局 Continuum MCP。

### OMP Global Bridge

默认路径：

```text
~/.omp/agent/extensions/continuum.ts
```

若设置：

```text
PI_CODING_AGENT_DIR
```

则使用对应 Agent Directory。

Global Extension 继续承载：

- lifecycle events；
- Managed Work Widget；
- Decision / Design Conflict UI；
- `/continuum-status`；
- `/continuum-off`。

### Project Auto Detection

Global Bridge 统一：

```text
cwd
→ upward search .continuum/project.yaml
```

未找到时：

```text
Codex → continue + suppressOutput
OMP   → SILENT
```

不读取、不创建、不修改项目状态。

### Agent-driven Project Operations

Codex MCP 与 OMP Extension 都提供：

```text
continuum_init
continuum_status
continuum_doctor
```

用于自然语言 Onboarding / 状态查询 / 诊断。

### Legacy Compatibility

旧项目级 Adapter 继续兼容：

```text
.codex/hooks.json
.omp/extensions/continuum.ts
```

Global Bridge 检测到旧 Adapter 时 defer，避免重复处理。

项目级安装命令保留但降为兼容 / 调试模式：

```bash
continuum host install codex --project
continuum host install omp --project
```

## 3. 没有改变的核心语义

P11 没有新增 Durable Domain State，也没有修改：

```text
Project
Change
Work Binding
Work Baseline
Snapshot
Reconcile
Design Conflict
Archive
```

因此这是 Host Integration Architecture 修正，不是生命周期重构。

## 4. OMP Profile 边界

P11 默认安装到 OMP 默认 user Agent Directory。

如果用户使用独立 OMP Profile，应在对应环境设置 `PI_CODING_AGENT_DIR` 后执行：

```bash
continuum setup --skip-codex
```

P11 不扫描并批量修改所有未知 Profile。

# P02｜Change 与 Artifact Graph 闭环实现说明

## 目标

在 P01 可移植 Project State 基础上，让 Continuum 能表达：

```text
Project
→ active Change
→ ArtifactRef
→ Typed Relation
```

## 本票实现

- Change `active / closed / superseded` 领域模型与迁移约束；
- ArtifactRef 领域模型，不复制 Artifact 正文；
- Relation：`belongs_to / blocked_by / governed_by / domain_context / evidence / supersedes`；
- Routing：`required / optional / historical`；
- Durable YAML persistence；
- Local `git-file` Artifact Authority；
- Artifact 当前内容 Git blob version；
- Relation endpoint existence validation；
- Duplicate Relation idempotency；
- Change 的 `specRefs / ticketRefs` 索引同步；
- `change open/list/show`；
- `artifact register/list`；
- `relation add/list`；
- `status` 展示 live active Change overlay。

## 关键边界

- Opening Change **不推进 Snapshot**；当前 active Change 从 Change Authority 动态读取。
- Snapshot 仍是 immutable convergence point；P06 Change Reconcile 才允许推进 Current Snapshot。
- ArtifactRef 只保存 locator / version / metadata；正文仍属于外部 Authority。
- P02 的 CLI Artifact / Relation 命令是 debug/admin surface，后续 P04 Matt Adapter 会负责自动 Observe + Register。

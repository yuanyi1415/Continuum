# P04｜Matt 接入与最小 Context Routing｜实现说明

## 实现范围

- Local Matt Artifact Observer：只观察 `CONTEXT.md` 与受控的 ADR / Spec / Ticket 目录；
- `continuum matt scan [--change]`：登记 ArtifactRef，并在显式 Change 下关联 Spec / Ticket；
- 重复 Artifact ID 冲突时 fail-closed，不静默选文件；
- Context Router：Typed Relation + Change spec refs，默认最多 2-hop；
- 只沿 Relation 正向路由，避免通过共享 Spec 拉入 sibling ticket；
- Required / Optional / Historical 分离；
- `continuum context <work>` 返回最小 Context Manifest；
- Context budget 为软阈值，不静默丢弃 Required Authority。

## 关键边界

- Matt 保持黑盒；Observer 只 Observe + Register；
- 不扫描整个 `docs/`；
- 不引入 RAG / Vector DB / Knowledge Graph；
- P04 不实现 Reconcile。

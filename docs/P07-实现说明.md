# P07｜Codex 原生适配闭环｜实现说明

## 目标

让 Continuum 在 Codex 中保持默认静默，但能够可靠接入宿主生命周期：

```text
SessionStart
UserPromptSubmit
Stop
SessionEnd
→ Continuum Lifecycle
```

并提供：

```text
DECISION → MCP Structured Elicitation first
          → deterministic Hook Gate fallback

BLOCK    → deterministic Hook Block
```

---

## 已实现

### 1. Codex Lifecycle Adapter

支持：

- `SessionStart`
- `UserPromptSubmit`
- `Stop`
- `SessionEnd`

Codex 原始事件先被转换成统一 Host Lifecycle Signal，再进入 Application Layer；Host Schema 不进入 Domain。

### 2. Explicit Work Intent

仅识别明确形式：

```text
implement P03
/implement P03
```

不会因为普通提及 P03 自动绑定。

绑定后：

- Work Baseline 首次冻结；
- 新 Codex Session 从 Worktree Binding 自动 resume；
- resume 不移动 Work Baseline；
- Context Router 生成最小 Required Context 摘要注入 Host Context。

### 3. Stable Checkpoint

`Stop / SessionEnd` 触发已有 Lifecycle Checkpoint。

Host Event 仍然只是 wake-up signal：

```text
Codex event
→ checkpoint
→ Git / Runtime facts
→ Work Reconcile
```

Hook 丢失时，显式 `continuum reconcile` 仍可从 Git 事实恢复。

### 4. DECISION

正式支持两种路径：

#### Primary：MCP Structured Elicitation

Codex 用户在 Hook Gate 提示后可发送：

```text
continuum decision
```

Hook 仅允许这条决策请求继续，并注入强约束：调用 MCP Tool `continuum_decision`，不得替用户选择。

MCP Server：

```text
runtime-assets/codex-mcp-server.mjs
```

它只负责 UI Renderer：

```text
pending InteractionRequest
→ Codex structured elicitation
→ InteractionResult
```

#### Fallback：Hook Gate

如果 MCP 不可用：

- UserPromptSubmit 被 deterministic block；
- 用户可直接回复选项编号或 option id；
- Adapter 确定性解析并 resolve；
- 不依赖 LLM 理解决策答案。

### 5. BLOCK

Pending `BLOCK` 会直接映射为 Codex Hook Block。

普通 Prompt 不能绕过。

Session 已显式 Suppress 时，当前 Session 完全退出 Continuum 管理；Worktree Binding 仍保留。

### 6. Host Installer

新增：

```bash
continuum host install codex
```

负责：

- 合并 `.codex/hooks.json`；
- 启用 `.codex/config.toml` 的 hooks；
- 在根 `AGENTS.md` 写入可识别的 Continuum managed block；
- 尝试注册 Codex MCP Server；
- 保留已有 Hook / config 内容；
- 重复安装幂等。

可使用：

```bash
continuum host install codex --skip-mcp
```

只安装 repo-local Hook。

### 7. Host Capability Detection

新增：

```bash
continuum host codex capabilities --json
```

运行时检测：

- Codex 是否存在；
- Hook 能力；
- MCP 能力；
- Blocking UI 基线能力。

不将 Codex 版本号硬编码进 Core 语义。

---

## 新增 CLI

```bash
continuum host install codex [--skip-mcp]
continuum host codex capabilities
continuum host codex hook
continuum host codex interaction next [--type DECISION|BLOCK]
continuum host codex interaction resolve <id> [--option OPTION]
```

`hook` 为宿主内部入口，不是普通用户日常命令。

---

## 边界

P07 没有：

- 新增 Project / Change / Work / Snapshot 语义；
- 修改 Work Reconcile 正确性模型；
- 实现 OMP；
- 实现 Archive；
- 让 MCP 成为 Authority；
- 让 LLM 成为 lifecycle correctness 来源。

MCP 仅负责最佳交互体验；Hook Gate 与 state-derived lifecycle 仍是正确性下限。

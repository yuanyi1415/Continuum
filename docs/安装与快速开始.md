# Continuum 安装与快速开始

## 1. 前置条件

必须：

```text
Git
Node.js 24 LTS
```

可选 Host：

```text
Codex CLI
Oh My Pi / OMP
```

Continuum 不依赖 Docker、常驻 Daemon、Redis、MySQL 或外部服务。

## 2. 安装 Continuum

推荐直接从 GitHub 全局安装：

```bash
npm install -g "github:yuanyi1415/Continuum"
```

验证：

```bash
continuum --version
continuum --help
```

如果仓库是 private，Git / GitHub 凭据必须具备访问权限。

源码开发安装：

```bash
git clone https://github.com/yuanyi1415/Continuum.git
cd Continuum
npm install
npm run compile
npm link
```

## 3. 第一次机器 Setup

安装 CLI 后执行一次：

```bash
continuum setup
continuum doctor --global
```

`setup` 自动检测本机 Host：

```text
Codex
→ 用户级 Hook
→ Continuum MCP

OMP
→ 用户级 Extension
```

这一层属于 User / Machine Scope，只需要安装一次。

以后新项目**不要重复执行**：

```text
continuum host install codex
continuum host install omp
```

## 4. 在项目中启用

Continuum Project 仍然是 opt-in。

### 推荐：直接告诉 Agent

在项目目录打开 Codex / OMP 后说：

```text
给这个项目启用 Continuum。
```

Global Bridge 给 Agent 提供 `continuum_init` Tool。

### CLI fallback

```bash
cd /path/to/project
continuum init --name "Project Name"
```

项目默认只创建：

```text
.continuum/          # Durable / Git tracked
.continuum-local/    # Runtime / gitignored
```

不会创建 `.codex/` 或 `.omp/`。

## 5. 日常使用

机器 setup 完成以后：

```bash
cd /path/to/project
codex
```

或者：

```bash
cd /path/to/project
omp
```

Global Bridge 自动检查：

```text
存在 .continuum/project.yaml
→ 启用 Continuum 生命周期

不存在
→ silent NOOP
```

普通聊天保持 unmanaged。

明确正式实现：

```text
implement P03
```

Continuum 才建立 / 恢复正式 Work。

## 6. 状态与诊断

机器级：

```bash
continuum doctor --global
continuum host doctor
```

项目级：

```bash
continuum status
continuum doctor
continuum doctor --recover
```

也可以直接问 Agent：

```text
看一下当前 Continuum 状态。
```

Agent 可调用 `continuum_status`。

## 7. 设计冲突

当当前实现与 Spec / ADR 冲突：

```text
发现设计冲突
→ 回到设计处理
→ 更新并提交设计 Authority
→ 再次 implement <Ticket>
→ 用户确认重新开始
→ 新 Work Baseline
```

用户不需要直接操作内部 BLOCK 状态。

## 8. 旧项目兼容

旧版项目可能已有：

```text
.codex/...
.omp/extensions/continuum.ts
```

Global Bridge 会 defer 给旧项目 Adapter，避免双重处理。

新项目不再使用这些文件。仅兼容 / 调试时显式：

```bash
continuum host install codex --project
continuum host install omp --project
```

## 9. OMP Profile

默认 OMP Global Bridge 安装在：

```text
~/.omp/agent/extensions/continuum.ts
```

若使用独立 Profile / Agent Directory，请设置：

```bash
PI_CODING_AGENT_DIR=<对应 agent dir> continuum setup --skip-codex
```

## 10. 项目归档

```bash
continuum archive
continuum archive --with-history
continuum archive verify <archive-path>
```

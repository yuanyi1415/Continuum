# P06 实现说明

P06 实现 Change Reconcile 与 Project Snapshot 推进：

- 汇总当前 Change 所需 Ticket 的 Work Reconcile Candidate；
- Candidate 必须已经集成到当前 Git HEAD；
- Tests / Review / Completion Evidence 必须全部 PASS；
- N3 产生 blocking DECISION；
- N4 产生 BLOCK；
- 成功路径写 immutable Change Reconcile 与 Snapshot；
- `current.yaml` 通过本地 lock + optimistic CAS 推进；
- CAS 后 Change 标记 closed；
- 支持 CAS 后 / Change close 前崩溃的幂等恢复；
- 支持从其它仍存在的 Git linked worktree 聚合 ephemeral candidate；
- Change 完成后清理对应 Work Binding 与 Pending Candidate。

P06 不实现 Codex / OMP Renderer；只输出统一 InteractionRequest 与 Generic machine-readable error。

- clone portability tests。

## 初始化前置

P01 要求 Git Repository 至少已有一个 commit。原因是 Initial Snapshot 必须有真实、稳定的 Git revision；不使用伪造 revision 或工作目录路径作为 baseline。

## 受限测试环境说明

正式依赖为 `yaml`、`ajv`、`better-sqlite3`。本执行环境无法从 npm registry 安装依赖，因此源码保留了**仅在显式 DEV 环境变量开启时**的标准库 fallback，用于本地验收：

```text
CONTINUUM_DEV_FALLBACKS=1
CONTINUUM_DEV_ALLOW_NODE_SQLITE=1
```

正常安装环境不会走 fallback：缺少正式依赖时会 fail closed。
